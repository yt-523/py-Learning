## 字面量
程序中，直接书写的固定值（数据）

| 整数（int）      | 10，-10                   |
| ------------ | ------------------------ |
| 浮点数（float）   | 3.1234，-9.0002           |
| 布尔（bool）     | True（1），False（0）（本质为int） |
| 字符串（str）     | “唯有drinker留其名”           |
| 空值（NoneType） | None（空）                  |
| 数据容器         | 列表/元组/集合/字典              |
## 变量
用来存储单个数据的==容器==（空间），把**容易变化**的数据存储在变量中
格式：变量名 = 变量值       num = 34545 或者 a,b = 4567,"hei"
变量的类型可以变化（动态类型语言）

## 标识符
为变量、函数、类等元素起的**名字**

> [!NOTE] 规则
> 1.只能包含字母、数字、下划线
> 2.不能数字开头
> 3.不能用关键字：True、False、None、and、or、if、else、elif、for、while等
> 4.严格区分大小写


> [!NOTE] 建议（变量名）
> 1.见名知意                //age、time、name
> 2.多个部分用下划线链接    //my_name、first_school
> 英文字母全小写        //

## 字符串
字符串有三种定义方式
1.双引号    “”
2.单引号    ''
3.三引号 """
        """
![[Pasted image 20260904205555.png]]
若是字符串里面想包含" " ' '，需要加转义字符

| 转义字符 | 含义    |
| ---- | ----- |
| \ '  | '     |
| \ "  | "     |
| \ n  | 换行    |
| \ t  | tab缩进 |

#### 字符串拼接(3种)

## 运算符
#### 算术运算符

| 运算符 | 描述    |
| --- | ----- |
| +   | 加法    |
| -   | 减法    |
| *   | 乘法    |
| /   | 浮点数除法 |
| //  | 整数除法  |
| %   | 取余    |
| **  | 幂指数   |
优先级
** >  / // % * > +-

#### 赋值运算符

| 运算符 | 描述              |
| --- | --------------- |
| =   | a = b表示将b的值赋值给a |
| +=  | a+=b表示a=a+b     |
| -=  | 同上              |
| *=  | 同上              |
| /=  | 同上              |
| %=  | 同上              |
| //= | 同上              |
| **= | 同上              |

#### 比较运算符
比较后返回一个布尔值

| 运算符 | 描述   |
| --- | ---- |
| ==  | 等于   |
| !=  | 不等于  |
| >   | 大于   |
| >=  | 大于等于 |
| <   | 小于   |
| <=  | 小于等于 |
#### 逻辑运算符
连接多个条件表达式，会返回一个布尔值

| 运算符 | 描述       |           |
| --- | -------- | --------- |
| and | 逻辑与（并且 ） | 都满足才为True |
| or  | 逻辑或（或者）  | 一个满足为True |
| not | 逻辑非（取反）  | 1变0，0变1   |

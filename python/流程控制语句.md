## 条件判断
if格式：
if 要判断的条件：                  //判断语句的结果必须为布尔值
	操作                              //操作要有缩进，条件为True

如果条件为False
else:
	操作

也可以使用elif进行多区间条件判断

例子：
if 0<a&&a<60:
	print("不合格")
elif a<80:
	print("良好")
else:
	print("优秀")

## 结构模式匹配
用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行模板的操作

match <条件>:
	case <条件1>:               \#普通条件
		执行
	case <条件2> if .......:     \#加入另一个条件判断
		执行
	case <条件3|条件4>:    \#或者
		执行
	case \_:                        \#都不行
		执行

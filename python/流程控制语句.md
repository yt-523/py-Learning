## 条件判断
if格式：
if 要判断的条件：                  //判断语句的结果必须为布尔值
	操作                              //操作要有缩进，条件为True

如果条件为False
else:
	操作

也可以使用elif进行多区间条件判断

例子：
if 0<a&&a<60:
	print("不合格")
elif a<80:
	print("良好")
else:
	print("优秀")

## 结构模式匹配
用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行模板的操作

match <条件>:
	case <条件1>:               \#普通条件
		执行
	case <条件2> if .......:     \#加入另一个条件判断
		执行
	case <条件3|条件4>:    \#或者
		执行
	case \_:                        \#都不行
		执行

## 循环
#### whlie
**通过条件表达式来控制是否进行下一次循环**
while 条件表达式:
	循环体语句1
	循环体语句2
	......

先判断==条件表达式==True还是False
True在执行，然后在判断，再执行。。。。。。
False就结束

while 条件表达式:

else:
	条件为False时会执行

只知道循环的条件，不知道次数
#### for
**轮询遍历机制，对一批内容逐个处理**
for 元素 in 待处理的数据集:
	循环体代码
else:
	循环结束执行代码

对已知的数据集进行遍历或者已知次数的行为

###### range：
1.range(end)
从0开始，到end结束的数字序列，不包含end
2.range(start,end)
从start开始，到end结束的数字序列，不包含end
3.range(start,end,step)
从start开始，到end结束的数字序列，step为步长，不包含end
